# Evo-WAM 冻结规格

## 研究主线

1. 用机器人实际交互建立可执行作用接口。
2. 用单视角人机任务对应数据、多时域监督和可选的可靠跨视角约束，训练同一个部署 WAM 的条件适配参数。
3. 在固定候选集合中独立检验动作后果预测是否改善选择。

首轮统一单候选，关闭 F 排序。不新增视角判别器、对比编码器或规划网络。

最新数据路线允许用非配对单视角视频先学习轻量作用表示 `Z_D`，随后冻结作用编码器、接入已有 R。
本轮用户确认视频损失只更新该编码器及训练期预测头；WAM 继续由机器人阶段训练。
同步多视角不再是主训练入口要求，完整定义与预算见 [unpaired_video.md](unpaired_video.md)。

## 数据与物理含义

`PhysicalOutcome` 按稳定场景实体索引保存运动、接触/抓持/支撑及已发生事件的时间序列。它不包含任务角色或“应该发生”的必要性判断。

`EffectRequirement` 保存任务角色到场景实体的绑定、允许的几何结果、控制关系、必要事件和适用时域。区分 `current` 与 `remaining`；剩余任务保留终点及必要顺序，不复制无关抓法、路径、速度和精确完成时间。

要求契约使用以下显式语义；`PhysicalOutcome` 不增加这些任务字段：

| 字段 | 形状与解释 |
| --- | --- |
| `geometry_tolerance` | 与 `geometry` 同形状，非负半宽；允许区间为 `geometry ± geometry_tolerance` |
| `event_windows` | `int64 [B,T,R,R,E,2]`，相对当前时刻的控制步闭区间 `[start,end]` |
| `event_precedence` | `int64 [B,P,2]`，必要的严格先后边；节点索引按 `[T,R,R,E]` 的行优先顺序展平 |

事件的 `T` 维表示要求槽位，窗口规定允许的发生时间，而不是要求恰好在 `step_offsets[T]` 发生。几何与关系仍按各自查询点检查；`current` 与 `remaining` 可使用不同查询网格。事件窗口允许在预测范围内改变执行速度，不能把窗口截断到实际执行前缀。预测未覆盖必要窗口时，不得忽略该要求。

`label_valid` 另含 `geometry_tolerance`（同几何形状）、`event_windows`（同事件形状，一个布尔值覆盖两个端点）、`event_precedence`（`[B,P]`）。顺序填充项 `(-1,-1)` 在有效掩码为 True 时表示已知不需要该边，为 False 时表示未知，不能充当无约束负例。已知先后边只引用必要的正事件，禁止自环、重复边、环及与已知窗口矛盾的先后要求。模型的顺序槽位上限首版为 4；数据契约本身允许任意 P，包括 0。

绑定使用非负场景槽位以及三个状态：`-1=UNUSED`、`-2=UNMATCHED`、`-3=UNCERTAIN`。必要角色不能标为 UNUSED；未匹配或证据不足时保留其全部任务要求并拒绝执行，不能删除要求或重绑干扰物。`required_roles` 返回参与必要条件的角色，`resolved` 仅表示必要绑定是否已确认；它不是完成判据。`semantics_known` 进一步要求必要值、容差、窗口及顺序槽位的监督均已知。

G/Q、监督损失和评分使用同一套区间／窗口／顺序定义。几何区间内的合法结果不产生越界误差；正事件只需在窗口内发生，负事件要求整个窗口内不发生。多条先后边必须使用同一组相容的事件发生时刻，不能逐边选择互相矛盾的局部最优时刻。顺序校验只处理这些时序约束，不新增机器人规划网络。

旧 Python 调用缺少新字段时，默认零容差、`[offset,offset]` 单点事件窗口和已知空顺序，仅保持旧固定时间语义的测试兼容。JSON v2 数据必须显式提供三个字段及其有效掩码；不能把兼容默认值当作从示范推断出的标注。新契约影响 G/Q 的输入与输出维度，检查点版本必须对应。

- `label_valid`：数据端决定监督是否可靠。模型不能预测它来关闭损失。
- `requirement_mask`：哪些条件属于操作要求。不得与标签有效性或预测不确定性混用。
- `prediction_uncertainty`：独立校准、诊断、非负代价或拒绝依据。增加不确定性不能删除要求或降低固定要求代价。
- 实体表、关系方向、坐标系和控制时间基准统一。换任务不能重排物理预测实体。丢失实体不等于关系不存在。
- 活跃任务的空要求、无效绑定和缺失必要实体不能成为零代价候选。
- 多种合法实现按完整合法配置或允许集合处理，不能逐字段拼接不同合法解。
- 第一阶段可从实际结果重新标记“已实现效果”；第二阶段的任务必要性还须有任务定义/审核标注。实际发生不等于任务必需。

## 模块与信息通路

读取器：`g = R(robot_history, Z_D, embodiment)`。`Z_D` 是按时间排列的示范作用 tokens；原始冻结视觉特征保留作原有对照。两种表示使用显式身份，不能静默混用。

WAM：`future = W(robot_history, g.current, g.remaining, embodiment)`。

动作专家：`actions = pi(robot_history, future, g.current, embodiment)`。

物理后果：`outcome = F(physical_history, candidate_actions, embodiment)`。

F 不读取示范、要求、生成未来或任务条件化缓存；可以共享冻结的纯观测编码。改变动作后半段不得改变前缀预测。任务替换只改变要求及其评分，不改变同一实际历史/候选的物理预测。

G/Q 在阶段一结束前支持 current/remaining 并通过重建检查。两阶段及部署使用同一语义接口。动作专家不突然接收未经训练的新条件。

## 训练

阶段一训练 G/Q、执行条件适配和 F。动作标签来自真实配对数据；失败按实际效果标记。不能用任意生成未来条件强制回归另一条记录动作。准确作用要求在生成未来路径上的闭环执行用于验收。

阶段二先固定 G/Q/W/pi/F 和本轮预训练的示范作用编码器，暖启动读取器。随后开放 W 的条件 LoRA、已有 IFP/MCP 与一个共享时间查询的交互辅助头；VAE、G/Q/F/pi 和离线示范作用编码器继续冻结。

执行一致性使用同一个生成未来 Vbar、加噪动作和动作时间步：

`L_exec = ||v_pi(noisy_action, tau, history, Vbar, g_pred.current) - stop_grad(v_pi(noisy_action, tau, history, Vbar, g_true.current))||^2`。

Vbar 由本步 W 权重从噪声生成，采样整个放在 no_grad 中。教师无梯度，学生动作专家参数冻结但其前向保留到 g 的梯度。此项是调用一致性蒸馏，不是新的真实动作监督。

`L2 = lambda_z * latent_loss + lambda_r * decoded_requirement_loss + lambda_exec * L_exec`。

联合训练另外以正常加噪前向计算近期视频、IFP 和交互损失，梯度通过主干表示 Phi 更新部署 W 的 LoRA。这个训练图的隐藏态/缓存不能冒充生成未来、进入动作蒸馏或 F。冻结参数不等于 no_grad。

IFP/MCP 复用固定上游版本的实现和配置。它及交互头只能通过 Phi 获得任务信息，不直接读示范、g 或泄漏目标的语言。推理删除辅助头。

交互辅助头预测指定时域的关系与实际事件分布，不回归一条唯一确定的远期运动，也不充当 F 或成功概率模型。不同时间域取各自真实窗口；不完整观测不得标为“事件未发生”，越界标签无效。

## 成对随机性与条件丢弃

单视角按一次监督训练。只有数据明确声明 `pair_kind="synchronized_views"` 的可靠两视角样本计算 CV；缺省 `none`，不会复制单视角或把两段非配对视频强行对齐。以下共用随机条件的规定针对该可选成对分支。

固定同一 B 历史、轨迹、实体表、监督窗口和目标 latent。对每个预测目标只采样一次时间步与噪声，再供两个示范视角使用。各 IFP 时域保留原有噪声/调度关系，不能把跨时域噪声全部绑成一个。

机器人随机编码和增强只做一次。首版成对比较路径关闭模型随机 dropout，示范采用确定性预处理。相同示范重复输入在固定随机性下，成对损失应近零。

90% 条件样本保留实际存在的一路或两路任务；10% 单独无任务生成样本仅计算近期视频和启用的 IFP 目标。关闭原 drop_icl/droptext_target 的独立随机入口，由统一采样器处理。主 ICL 输入固定空任务文本。

无任务分支清空示范、current、remaining、任务文本与条件化缓存，保留真实机器人历史。跳过要求监督、执行蒸馏和跨视角损失，避免无条件学生匹配持有真值要求的教师。

## 字段损失

对象绑定在同一实体表上为 categorical 分布。可共存的接触、抓持、支撑分别为 Bernoulli；事件按同一定义与时间窗为 Bernoulli。不能对可共存关系做互斥 softmax。

跨视角离散字段使用自然对数、FP32 Jensen-Shannon divergence。字段内有效实体/关系/时域先取均值，再用固定字段权重汇总；权重初始为 1。合法等价类按标注合并概率质量，保留不合法质量。连续几何保留真值监督，不对坐标做 softmax。

`L_cv = sum(m_f * w_f * JS(p1_f,p2_f)) / sum(m_f * w_f)`。

先统一索引再取数据端共同有效交集。预测置信度/未知/requirement mask 不能改变分母。没有共同有效字段只跳过该对 CV，保留单视角监督；跨样本按有效对数平均并报告覆盖率。两个分支都接受 CV 梯度。

`L_pair = (L_sup_view1 + L_sup_view2)/2 + lambda_cv * L_cv`。

V0 与 V1 共用样本对、噪声、两路前向和监督均值，唯一差别是 lambda_cv=0 或验证集锁定的正值。成对 JS 是已有正则化，不主张全新学习原理。

## 数据划分与对照

同一人类原始演示的所有视角/增强、同一机器人轨迹的所有窗口保持同组；多对多人机配对按连通组划分。同任务不等于同一物理未来。不同合法轨迹保留各自标签。禁止未经参照系同步处理的镜像增强。

T0：近期目标；T1：加 IFP；T2：再加交互辅助目标。V0=T2 普通多视角训练；V1 增加成对项。主干可训练范围、数据池、预算和采样协议一致，记录实际步数/GPU时/采样成本。已有检查点继承 IFP 训练影响，因此这是继续使用该目标的增量。

几何接口与完整接口获得同样 IFP、交互辅助监督和成对训练。几何接口显式输入/监督只有绑定与几何；完整接口再含控制关系/必要事件。固定 token 预算和有效适配容量，不能把几何 tokens 永久屏蔽。共同 CV 字段为共同绑定输出和交互头关系/事件输出；完整接口额外 C/E 标签仅进入接口监督。

同一初态四条件：正面/侧面 × 放左/放右。检查绑定、remaining 与后续分叉，不要求共同抓取前缀立即不同。再测几何近似但保持/解除抓持要求不同的情况。辅助头删除后，换视角仍做对、换任务正确变化、换控制要求正确变化，才是主要证据。

## 缓存与候选评测

示范/视角、文本、绑定、任务进度或模型版本变化时重算任务条件缓存。历史、实体表、标定变化时更新纯观测缓存。执行每个前缀后更新历史。固定随机性下缓存与完全重算一致。

第一轮始终单候选。之后在训练划分上对当前策略候选分布做一次有限 F 适配，验证集锁定评分尺度/阈值。新增真实交互计入并提供给匹配数据基线。

四候选共用同一集合，比较随机、打乱评分和 F 排序。执行前缀 ell=max(1,floor(H/4))。F 的全窗口预测表示完整执行候选的后果，不能冒充前缀重规划的闭环结果。

只执行前缀只能监督原候选的前缀；续接策略结果须配实际续接动作，不能标给原候选后半段。局部 Oracle@4 从同一完整仿真快照执行各前缀，再用同一个冻结续接规则、预算和配对随机性继续；不是全系统严格上界。前缀进展、局部 Oracle、闭环任务成功率分开报告。

## 基座、验收与停止条件

Zero-WAM 固定提交：08e2c4ae41e2b63573a299825cebe6753481407c。主初始化 zero-wam-pretrain；公开权重复评与公开子集重训分开。完整模型为 10.8B，不能只按视频分支5B估算资源。RoboTwin 原始/修改成功判据双报，任务划分43/7；HOST 后置。

P0 覆盖：类型/标签来源、实体置换、掩码防退化、任务不变性、时间因果性、直接/采样梯度隔离、重复示范与随机配对、JS边界/空集/尺度、条件丢弃、合法实现、前缀标签、数据划分、缓存失效。

训练和实机资源待定，计划三个训练种子；正式数量与最小有用提升由独立 pilot 预登记。真实未来是相容状态下的诊断参考，不是必须追平的上界。合成测试不能作为机器人成功率。

若 CV 无额外执行收益则撤回其增量主张；一致性升而任务区分降则拒绝该配置。若 F 不改善固定候选选择则撤回排序贡献。停止继续扩展架构。
